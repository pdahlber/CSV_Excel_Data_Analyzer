# CSV and Excel Data Analyzer

A Python/Streamlit application that allows users to upload CSV and Excel files, clean and explore their data, visualize key metrics, and generate AI-powered insights.

## Features:
- Upload CSV and Excel files
- Detect and remove duplicate rows and rows containing missing values
- Download the cleaned data
- Detect categorical, date, and numerical columns
- Filter data by category and date-range
- View summary metrics for a selected numerical column
- Perform grouping and aggregation analysis
- Create interactive visualizations
- Generate AI powered insights based on the analyzed data

## How to Run the Application:
1. Clone this repository and open the project folder.
2. Install the required Python packages:
```
pip install -r requirements.txt
```
4. Start the Streamlit application:
```
streamlit run app.py
```
The application will open in your web browser.

## AI Insights:
The AI Insights feature analyzes the user's selected dataset, summary metrics, grouping analysis, and applied filters to generate natural-language observations about the data.

The AI model does not receive the raw dataset itself. Instead, it receives the relevant analytical context generated by the application. This allows the model to interpret the results of the analysis rather than simply being asked to "look at the CSV."
